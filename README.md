# Voice Request API — Sapa голостық робот/CRM бағытына арналған backend

Клиент сұраныстарын қабылдап, кезекке салып, асинхронды өңдейтін және
нәтижені қайтаратын production-ready MVP. CRM клиенттік жазба CRUD-ы
JWT + рөлдік бақылаумен қоса берілген.

## Стек
Python 3.12 · FastAPI · Pydantic v2 · PostgreSQL 16 · Redis 7 · SQLAlchemy 2.0 (async) · Alembic · Docker
